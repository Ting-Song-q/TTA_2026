# tta/arm 脚本运行说明

目录：`tta/arm/`


| 脚本         | 作用                                         |
| ---------- | ------------------------------------------ |
| `start.py` | Feetech 总线机械臂：列串口、扫舵机、读位置、开环抓取序列           |
| `grasp.py` | 相机检测前方红色方块 + 视觉伺服对准 + 抓取（复用 `start.py` 总线） |


硬件约定（脚本内默认）：

- 舵机：Feetech STS3215，ID `0..5`（肩偏航～夹爪）
- 串口：常见 `/dev/ttyACM0` 或 `/dev/ttyUSB0`
- 波特率：`115200`，协议：`0`（可用 `--scan` 现场确认后再改脚本顶部常量）
- 相机（仅 `grasp.py`）：默认 `/dev/video11`

## 环境依赖

建议在已安装 LeRobot 的 conda/venv 中运行。

```bash
# 机械臂总线
pip install "lerobot[feetech]"
# 或
pip install feetech-servo-sdk pyserial

# 视觉抓取额外需要
pip install opencv-python numpy
```

Linux 串口权限（一次即可）：

```bash
sudo usermod -aG dialout $USER
# 重新登录后生效
```

进入目录：

```bash
cd ~/tta/arm   # 或你的实际路径，如 /home/tta/tta/arm
```

## 1. `start.py` — 总线工具与开环抓取



### 1.1 列出串口

```bash
python3 start.py --list-ports
```

确认设备描述是舵机 USB 转 TTL 适配器，而不是其它 USB 设备。

### 1.2 扫描舵机 ID / 波特率 / 协议

```bash
python3 start.py --port /dev/ttyACM0 --scan
# 可选指定：
python3 start.py --port /dev/ttyACM0 --scan --baud 115200 --protocol 0
```

扫到后按终端提示，必要时修改 `start.py` 顶部：

- `PROTOCOL_VERSION`
- `DEFAULT_BAUD`
- `MOTORS` 中的 `id` / `model`



### 1.3 只读当前位置（不运动）

```bash
python3 start.py --port /dev/ttyACM0 --read
```

不写 `--port` 时会自动选第一个 `ttyACM*` / `ttyUSB*`。

### 1.4 执行开环抓取动作

```bash
python3 start.py --port /dev/ttyACM0
```

动作顺序（位姿在脚本内 `GRASP_*` 常量中标定）：

1. 观察位 + 张开夹爪
2. 接近上方
3. 下降到抓取点
4. 闭合夹爪
5. 抬起
6. 收回待机（夹爪保持闭合）

结束后会卸力矩并断开连接。

### 1.5 常用参数


| 参数             | 说明                         |
| -------------- | -------------------------- |
| `--port`       | 串口，如 `/dev/ttyACM0`、`COM3` |
| `--list-ports` | 列串口后退出                     |
| `--scan`       | 扫描舵机                       |
| `--baud`       | 指定波特率                      |
| `--protocol`   | `0` 或 `1`                  |
| `--read`       | 只读位置，不抓取                   |




### 1.6 现场标定提示

- 关节目标为原始 ticks（约 `0~4095`，中位常约 `2048`）
- 改 `GRASP_OBSERVE` / `GRASP_APPROACH` / `GRASP_DOWN` / `GRASP_LIFT` / `GRASP_HOME`
- 夹爪方向反了：交换 `OPEN_GRIPPER` 与 `CLOSE_GRIPPER`
- 幅度先小，确认方向正确后再加大



### 1.7 扫不到舵机时排查

1. 舵机是否单独供电，GND 与 USB 适配器共地
2. `--list-ports` 确认串口是否为舵机适配器
3. 若是旧 PWM 舵机（`#xxxP1500!` 协议），本脚本不适用
4. 换口再试：`python3 start.py --port /dev/ttyUSB0 --scan`

## 2. `grasp.py` — 视觉定位红色方块并抓取

依赖同目录 `start.py`（总线连接、读写位置）。

### 2.1 推荐调试顺序

**① 只测相机与红色检测（机械臂不动）**

```bash
python3 grasp.py --camera 11 --dry-run
```

调试图默认写到：

`~/Desktop/grasp_test/debug/tta_arm_grasp/`

确认画面里能框到红色方块后再上真机。

**② 真机视觉伺服 + 抓取**

```bash
python3 grasp.py --port /dev/ttyACM0 --camera 11
```



### 2.2 流程说明

1. 机械臂到观察位，夹爪张开
2. HSV+RGB 检测红色方块中心
3. 视觉伺服：`shoulder_pan` 左右、`reach` 前后对准
4. 高位接近 → 下降 → 闭合 → 抬起（夹爪保持闭合）
5. 复位到观察位（夹爪仍闭合）



### 2.3 常用参数


| 参数             | 说明                              |
| -------------- | ------------------------------- |
| `--port`       | 舵机串口；`--dry-run` 时可省略           |
| `--camera`     | 摄像头编号，默认 `11`（即 `/dev/video11`） |
| `--dry-run`    | 只检测并保存调试图，不控制机械臂                |
| `--list-ports` | 列串口后退出                          |




### 2.4 现场主要改 `CFG`（脚本内）

- 相机：`camera_index`、分辨率  
- 红色阈值：`hsv_*`、`min_r` 等  
- 图像目标点：`x_center` / `y_center`  
- 伺服增益：`x_pid_p` / `y_pid_p`  
- 关节位姿：`observe_pose`、`approach_pose`、`grasp_pose`、`lift_pose`  
- 夹爪：`open_gripper` / `close_gripper`（方向反了就对调）



### 2.5 常见失败


| 现象           | 处理                                          |
| ------------ | ------------------------------------------- |
| 打不开相机        | 换 `--camera`；检查 `/dev/video*` 与占用进程         |
| `前方未检测到红色方块` | 调光/`roi`/HSV；先看 `--dry-run` 调试图             |
| 对准超时仍抓       | 放宽 `stable_err_*` 或加大 `track_timeout`；改 PID |
| 串口连不上        | 先跑 `start.py --scan` / `--read`             |

## 建议上机流程（摘要）

```bash
cd ~/tta/arm

# 1) 确认串口与舵机
python3 start.py --list-ports
python3 start.py --port /dev/ttyACM0 --scan
python3 start.py --port /dev/ttyACM0 --read

# 2) 可选：开环走一遍抓取（不依赖相机）
python3 start.py --port /dev/ttyACM0

# 3) 视觉：先 dry-run，再真抓
python3 grasp.py --camera 11 --dry-run
python3 grasp.py --port /dev/ttyACM0 --camera 11
```

安全注意：首次上电请保证臂周围无碰撞物；开环位姿未标定前幅度保持保守；视觉抓取前务必确认夹爪开合方向正确。
