# 空地协同通信协议（无人机端说明）

> 适用地面端：`nav_rescue_2026.py` + `rescue_protocol.py`  
> 配置文件：`mission_config.yaml` → `comm` / `timeouts`  
> 仿真参考：`test/sim_drone.py`、`test/sim_protocol.py`  
> 文档日期：2026-07-21

---

## 1. 通信方式总览

小车与无人机**不使用 ROS topic**，统一采用：

- **传输**：小车通过 **SSH** 登录无人机主机
- **载体**：无人机本地文件（CSV / 空 flag）
- **约定**：文件写在无人机侧的 `/mnt/` 目录下

共 **4 次** 握手：


| 次序  | 方向       | 文件                        | 含义         |
| --- | -------- | ------------------------- | ---------- |
| 1   | 无人机 → 小车 | `/mnt/rescue_cmd.csv`     | 下发救援区编号与等级 |
| 2   | 小车 → 无人机 | `/mnt/loading_done.flag`  | 装货完成，可以起飞  |
| 3   | 无人机 → 小车 | `/mnt/delivery_done.flag` | 无人机投送完成    |
| 4   | 小车 → 无人机 | `/mnt/unload_done.flag`   | 小车在救援区卸货完成 |

## 2. 时序图

```
无人机巡检结束
    │
    ▼
① 写 rescue_cmd.csv  (target_zone, level)
    │
    │   小车 SSH 轮询读取并删除
    ▼
小车：取货 → 装货区 → 放到无人机平台
    │
    ▼
② 小车 SSH touch loading_done.flag
    │
    │   无人机检测到后删除，起飞投送
    ▼
无人机：飞往救援区并完成投送
    │
    ▼
③ 无人机 touch delivery_done.flag
    │
    │   小车 SSH 轮询读取并删除
    ▼
小车：驶向救援区 → 卸货到 100×100 放置区
    │
    ▼
④ 小车 SSH touch unload_done.flag
    │
    │   无人机检测到后删除，确认本轮结束
    ▼
小车返航停车区；无人机可进入下一轮或结束
```

## 3. 网络与账号

小车读取 `mission_config.yaml`：

```yaml
comm:
  drone_host: "192.168.244.70"      # 无人机主机 IP（小车 SSH 目标）
  drone_user: "forlinx"
  drone_password: "forlinx"
  rescue_cmd_path: "/mnt/rescue_cmd.csv"
  loading_done_path: "/mnt/loading_done.flag"
  delivery_done_path: "/mnt/delivery_done.flag"
  unload_done_path: "/mnt/unload_done.flag"

timeouts:
  wait_drone_cmd: 120   # 等待 rescue_cmd.csv（秒）
  delivery: 300         # 等待 delivery_done.fl
```

无人机端要求：

1. 开启 SSH，账号可登录
2. `/mnt` 可写
3. 与小车同一局域网，IP 与配置一致

## 4. 信号详细说明



### 4.1 `rescue_cmd.csv`（无人机 → 小车）


| 项    | 内容                                           |
| ---- | -------------------------------------------- |
| 路径   | `/mnt/rescue_cmd.csv`                        |
| 写入方  | 无人机（巡检确定待救援点后）                               |
| 读取方  | 小车 `wait_for_rescue_cmd()`，约 1s 轮询，默认超时 120s |
| 读后处理 | **小车删除该文件**                                  |


推荐格式：

```csv
target_zone,level
2,1
```

兼容字段（地面端也可解析）：

```csv
救援点,救援等级
救援点2,1级
```

字段含义：


| 字段            | 说明             |
| ------------- | -------------- |
| `target_zone` | 救援区编号，整数 `1~4` |
| `level`       | 救援等级，整数        |


Python 写入示例：

```python
import csv

def write_rescue_cmd(path="/mnt/rescue_cmd.csv", zone=2, level=1):
    with open(path, "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=["target_zone", "level"])
        writer.writeheader()
        writer.writerow({"target_zone": zone, "level": level})
```

Shell 写入示例：

```bash
cat > /mnt/rescue_cmd.csv << 'EOF'
target_zone,level
2,1
EOF
```

注意：

- 多轮任务时，每轮开始前应**覆盖写入**新文件
- 旧文件若仍存在，可能被小车误读；建议写前先 `rm -f /mnt/rescue_cmd.csv`

### 4.2 `loading_done.flag`（小车 → 无人机）


| 项    | 内容                       |
| ---- | ------------------------ |
| 路径   | `/mnt/loading_done.flag` |
| 写入方  | 小车（装货到无人机平台后）            |
| 写入方式 | SSH 执行 `touch`           |
| 读取方  | 无人机轮询                    |
| 读后处理 | **无人机应删除该文件**            |


无人机检测示例：

```python
import os
import time

LOADING_DONE = "/mnt/loading_done.flag"

while True:
    if os.path.exists(LOADING_DONE):
        os.remove(LOADING_DONE)
        # 起飞前往救援区
        break
    time.sleep(0.2)
```

```bash
# 轮询
while [ ! -e /mnt/loading_done.flag ]; do sleep 0.2; done
rm -f /mnt/loading_done.flag
# 然后起飞
```

注意：地面端 `notify_loading_done()` 会**一直重试**直到 `touch` 成功。

---



### 4.3 `delivery_done.flag`（无人机 → 小车）


| 项    | 内容                                              |
| ---- | ----------------------------------------------- |
| 路径   | `/mnt/delivery_done.flag`                       |
| 写入方  | 无人机（在救援区完成投送后）                                  |
| 写入方式 | `touch /mnt/delivery_done.flag`                 |
| 读取方  | 小车 `wait_for_delivery_done()`，约 2s 轮询，默认超时 300s |
| 读后处理 | **小车删除该文件**                                     |


无人机写入：

```bash
touch /mnt/delivery_done.flag
```

```python
from pathlib import Path
Path("/mnt/delivery_done.flag").touch()
```

注意：写完后小车才会驶向救援区；超时未出现则小车任务中止。

---



### 4.4 `unload_done.flag`（小车 → 无人机）**【新增】**


| 项    | 内容                      |
| ---- | ----------------------- |
| 路径   | `/mnt/unload_done.flag` |
| 写入方  | 小车（救援区卸货完成后）            |
| 写入方式 | SSH 执行 `touch`          |
| 读取方  | 无人机轮询                   |
| 读后处理 | **无人机应删除该文件**           |


含义：小车已完成地面侧卸货，本轮空地协同可收尾。

无人机检测示例：

```python
import os
import time

UNLOAD_DONE = "/mnt/unload_done.flag"

while True:
    if os.path.exists(UNLOAD_DONE):
        os.remove(UNLOAD_DONE)
        # 本轮结束 / 进入下一轮
        break
    time.sleep(0.2)
```

```bash
while [ ! -e /mnt/unload_done.flag ]; do sleep 0.2; done
rm -f /mnt/unload_done.flag
```

## 5. 无人机端推荐状态机

```
IDLE
  │ 巡检完成
  ▼
WRITE_RESCUE_CMD          ← 写 rescue_cmd.csv
  │
  ▼
WAIT_LOADING              ← 轮询 loading_done.flag，存在则删除
  │
  ▼
TAKEOFF_AND_DELIVER       ← 起飞、投送
  │
  ▼
WRITE_DELIVERY_DONE       ← touch delivery_done.flag
  │
  ▼
WAIT_UNLOAD               ← 轮询 unload_done.flag，存在则删除
  │
  ▼
MISSION_DONE / NEXT_ROUND
```

参考实现：`test/sim_drone.py`

## 6. 与小车任务状态对应关系


| 小车状态                 | 通信动作                     |
| -------------------- | ------------------------ |
| `WAIT_DRONE_CMD`     | 等 ① `rescue_cmd.csv`     |
| `NOTIFY_TAKEOFF`     | 发 ② `loading_done.flag`  |
| （装货后等待）              | 等 ③ `delivery_done.flag` |
| `NOTIFY_UNLOAD_DONE` | 发 ④ `unload_done.flag`   |

## 8. 常见问题

**Q1：小车连不上无人机？**  
检查 IP、SSH、防火墙，以及 `drone_user` / `drone_password`。

**Q2：写了** `rescue_cmd.csv` **小车无反应？**  
确认路径为 `/mnt/rescue_cmd.csv`，且含表头与有效数据行。

**Q3：**`loading_done.flag` **写了但无人机不飞？**  
确认无人机轮询的是**本机** `/mnt/loading_done.flag`，并在检测后删除。

**Q4：**`delivery_done.flag` **写了但小车不动？**  
确认文件确实写在无人机主机 `/mnt/`，且在超时时间内；小车读后会删除。

**Q5：收不到** `unload_done.flag`**？**  
确认无人机在投送后进入 `WAIT_UNLOAD` 轮询；小车仅在卸货成功后才 touch。
