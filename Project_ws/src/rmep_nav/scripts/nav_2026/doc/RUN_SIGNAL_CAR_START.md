# 无人机 -> 小车 启动信号对接说明（最小通信版）

本文档不是运行说明，而是给小车侧同学看的**交接文档**。
目的只有一个：说明当前无人机侧在“启动小车”这个动作上，具体是**往哪里写、写什么、什么时候写、会不会复位**，方便小车侧判断自己是否需要适配代码。

## 1. 当前方案概述
当前最小通信方案采用：

```text
同一局域网 + 小车 SSH 到无人机主机 + 读取无人机主机 /mnt/ 下的文件
```

也就是说：

- 文件真实存在于 **无人机算力盒子主机** 上
- 小车不是读自己本地文件
- 小车应通过 SSH 或等效远程方式读取无人机主机上的 `/mnt/rescue_cmd.csv`

## 2. 无人机侧当前写入的文件
无人机侧当前只写一个启动信号文件：

```text
/mnt/rescue_cmd.csv
```

这是一个 CSV 文件，不是 flag 文件。

## 3. 文件内容格式
当前无人机侧写入格式固定为两列：

```csv
target_zone,level
1,1
```

字段说明：

- `target_zone`：目标救援区编号
- `level`：等级

目前为了先打通流程，默认值写死为：

- `target_zone = 1`
- `level = 1`

也就是说，当前这条信号的语义可以理解成：

```text
无人机已经完成当前阶段，小车可以启动；
同时默认附带一个占位目标：救援区 1，等级 1。
```

如果小车侧当前只需要一个“可以启动”的触发条件，那么只要检测到该文件存在并成功读到即可。
如果小车侧已经按正式协议实现了 `target_zone` / `level` 解析，那么当前也兼容。

## 4. 无人机侧什么时候写这个文件
当前有两种方式：

### 方式 A：最小通信测试脚本
无人机侧运行：

```text
signal_car_start.py
```

该脚本**不控制飞行**，只做一件事：

```text
写 /mnt/rescue_cmd.csv
```

适合双方先单独验证通信是否打通。

### 方式 B：飞行脚本结束后
当前部分飞行脚本在完成降落后，也会写同样的 `/mnt/rescue_cmd.csv`，表示：

```text
无人机阶段完成，小车可以启动。
```

## 5. 无人机侧是否会复位旧文件
会。

当前无人机侧遵循的原则是：

```text
谁写，谁主负责复位
```

因此在最小通信测试脚本启动时，无人机侧会先复位自己负责的文件：

- `/mnt/rescue_cmd.csv`
- `/mnt/delivery_done.flag`

也就是说，每次重新测试前：

- 旧的 `rescue_cmd.csv` 会先被删除
- 然后无人机再写入新的 `rescue_cmd.csv`

## 6. 小车侧当前需要确认的内容
小车侧请确认以下几点：

### 6.1 路径是否一致
当前无人机侧固定写入：

```text
/mnt/rescue_cmd.csv
```

小车侧如果轮询的是别的路径，需要改成一致。

### 6.2 读取方式是否兼容 CSV
当前文件不是纯文本单值，而是：

```csv
target_zone,level
1,1
```

如果小车侧现在只支持“看到文件就启动”，那可以只判断文件存在。
如果小车侧已经支持 CSV 解析，请确认字段名兼容：

- `target_zone`
- `level`

### 6.3 是否需要删除文件
当前建议：

- `rescue_cmd.csv` 由无人机侧在**下一次启动前复位**
- 小车侧**不强制要求删除**这个文件

这样做的原因是：

- 当前它更像“当前任务参数”
- 而不是“一次性的瞬时 flag”

如果小车侧已经实现“读完后删除”，请提前和无人机侧确认是否要统一策略。

## 7. 当前对接建议（最小改动）
如果小车侧现在只想先验证链路是否通，推荐采用最简单兼容策略：

### 小车侧最小判断逻辑
```text
1. 能 SSH 到无人机主机
2. 能读取 /mnt/rescue_cmd.csv
3. 文件存在即认为“无人机允许启动”
4. 如果能解析 CSV，则读取 target_zone 和 level
```

### 无人机侧最小行为
```text
运行 signal_car_start.py
-> 复位旧文件
-> 写 /mnt/rescue_cmd.csv
```

## 8. 后续可能扩展
当前只是“最小通信版”，后续如果比赛流程继续推进，还可能用到：

- `/mnt/loading_done.flag` （小车 -> 无人机）
- `/mnt/delivery_done.flag` （无人机 -> 小车）

但这些还不是这次交接必须适配的内容。

## 9. 需要小车侧给的反馈
请小车侧同学确认以下问题：

1. 当前是否已经实现读取 `/mnt/rescue_cmd.csv`
2. 当前是“只检测文件存在”还是“解析 CSV 字段”
3. 如果解析字段，是否支持：
   - `target_zone`
   - `level`
4. 当前是否会在读取后删除该文件
5. 是否需要无人机侧改成别的字段名或别的路径

## 10. 结论
当前无人机侧对外暴露的最小启动信号是：

```text
文件路径：/mnt/rescue_cmd.csv
文件格式：CSV
字段：target_zone, level
默认内容：1,1
触发语义：小车可以启动
```

如果小车侧能兼容这 4 点，那么当前通信链路就可以先打通。
